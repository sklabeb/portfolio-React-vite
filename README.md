# PortfolioPro

**Build and manage your professional portfolio in one place.**

PortfolioPro is a web application developed using React and Vite. It helps students organize their profile, skills, projects, achievements, and education into a professional digital portfolio. The application includes separate User and Admin modules.

## Features

- **User Authentication:** Sign up and log in to access a personal dashboard.
- **Dashboard Analytics:** View portfolio statistics and profile completion progress.
- **Profile Customization:** Update profile information, upload a profile picture, and customize the theme.
- **Portfolio Management:** Organize skills, projects, achievements, and education details.
- **Resume Builder:** Create a resume and export it as a PDF.
- **Admin Dashboard:** Search and manage registered users.

## Technologies Used

- React – component-based user interface
- Vite – development server and build tool
- HTML, CSS, and JavaScript – structure, styling, and application logic
- Vercel – deployment

## Project Modules

### User Module

Users can create an account, manage their portfolio information, customize their profile, track completion progress, and generate a resume.

### Admin Module

Administrators can access a dedicated dashboard to search and manage users.

## Run Locally

Clone the repository:

`git clone https://github.com/sklabeb/portfolio-React-vite.git`

Open the project folder:

`cd portfolio-React-vite`

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

Open the local URL displayed in your terminal.
